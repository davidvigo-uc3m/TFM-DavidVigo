# TFM_DavidVigo_UC3M

# Repositorio del servicio piloto ConsultaSaldoService

Servicio SOAP piloto desarrollado para validar una metodología de modernización desde tecnologías basadas en javax.* hacia Jakarta EE y Spring Boot 3.

# Archivos incluidos:

- Carpeta source con los stubs, capas de servicio, clases de prueba, Contrato WSDL.
- Dockerfile y Jenkinsfile utilizados para la construcción del pipeline automatizado.
- Fichero de configuración pom.xml con dependencias necesarias.
